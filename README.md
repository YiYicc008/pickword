# 拾词 · 电子英语单词本

拾词（Pickword）是一个在浏览器中运行的英语单词本。纯前端实现，零依赖、无构建步骤；数据默认保存在本机，配置 Supabase 后可在多台设备间同步。

## 功能

- 多个单词本，可自定义名称与颜色，各自独立计数；
- 录入单词时自动获取音标、词性、多义项中文释义与发音；
- 每个单词带权重：首次加入为 1，同一单词再次加入同一单词本时加 1；
- 列表视图按权重或加入时间排序，支持升序、降序与搜索；
- 词云视图以节点表示单词，按变式、同义、反义、形近等关系结成词团，多个词团构成词云；
- 详情中可拖动排序释义、修改词性与中文、添加自定义释义；
- 可选能力：AI 分类与关系生成、Supabase 多设备同步、添加到主屏幕后离线使用。

## 使用方式

### 直接访问

<https://YiYicc008.github.io/pickword/>

需查看示例数据时，在地址后加 `?demo`。

### 在本机运行

双击 `start.bat`。脚本启动本地静态服务并打开浏览器，同时在控制台打印可供同一 WiFi 下其他设备访问的地址。

启动脚本优先使用 Node.js，未安装时回退 Python 3。窗口即服务，关闭后页面不可访问。若默认端口被占用，端口会自动顺延，以控制台输出的地址为准。

### 部署为独立站点

将目录推送至 GitHub 仓库，进入 **Settings → Pages**，Source 选择 `Deploy from a branch`，Branch 选择 `main`，目录保持 `/(root)`，保存后约一分钟即可访问 `https://<用户名>.github.io/<仓库名>/`。

所有资源使用相对路径，可部署于子目录；根目录的 `.nojekyll` 用于跳过 Jekyll 处理。亦可部署至 Netlify、Vercel、Cloudflare Pages 等静态托管服务。

### 添加到主屏幕

- iPad（Safari）：分享 → 添加到主屏幕；
- Android / HarmonyOS：浏览器菜单 → 添加到桌面；
- Windows（Chrome / Edge）：地址栏右侧的安装图标。

添加后以独立窗口启动，离线可用。

## 录入与释义

点击右上角「添加单词」，或按快捷键 `n`。支持以逗号或换行分隔批量录入，并可多选目标单词本；「AI 智能分类」由 AI 判断应归入的单词本（需先配置 AI）。

音标、词性与释义来自 dictionaryapi.dev，发音依次尝试有道音频、词典音频、浏览器语音合成，结果在本机缓存 30 天。词典中同一单词存在多个词性时，每个词性各列一条义项：列表显示前两条，详情显示全部；词性与义项按常用度排序，生僻义项在详情中淡化并标注「冷僻」。

词典接口异常或限流时，单词仍会加入，释义留空，工具栏出现「补全释义 N」，点击后重新查询缺失项。

### 编辑释义

详情中最上方的释义卡片可直接编辑：

- 点击词性或中文修改内容；
- 按住卡片拖动调整顺序，松手后按新顺序保存；触屏设备请按住左侧手柄拖动；
- 点击「+ 添加释义」新增自定义义项，点击 `×` 删除。

列表按编辑后的顺序显示。手动修改过的单词在重新获取时默认保留。

### 权重

单词首次进入某个单词本时权重为 1，同一单词再次进入同一单词本时加 1。权重显示在单词右侧；悬停单词行或进入详情可手动增减。

### 两种视图

- **列表**：按权重（高→低、低→高）或加入时间（新→旧、旧→新）排序，支持按英文或中文释义搜索；
- **词云**：节点为单词，连线表示关系。相关单词组成词团并以同一色调的轮廓标示；同一单词属于多个词团时，节点以分段彩色圆环表示归属。可切换词云、拖拽平移、缩放，点击节点查看详情。

词云视图右上角提供以下操作：

- **整理词团**：依据已有关系自动聚类为词团；
- **AI 生成词云**：由 AI 自行分组，生成一至三个词云（需配置 AI）；
- **AI 生成关联**：由 AI 判断词与词之间的关系并连线（需配置 AI）；
- **词团 / 词云**：手动新建、改名、改色、增删成员。

### 全部重新获取

工具栏的「全部重新获取」用于重新查询当前单词本内所有单词的音标、发音、词性与释义。词典接口存在速率限制，程序逐个查询并可在中途取消；查询失败的单词保留原有内容。手动编辑过释义的单词默认保留，确认框中可选择覆盖。

## 配置 AI（可选）

在 **设置 → AI 服务** 中选择服务商、接口地址、模型，填入 API Key 后点击「测试连接」。支持 DeepSeek、OpenAI、Moonshot 及任意 OpenAI 兼容接口，Key 仅保存在本机浏览器。

未配置 AI 时，智能分类、义项翻译与关系生成需手动完成。

## 多设备同步（可选）

同步基于 Supabase 免费版，数据保存在使用者本人的项目中，通过行级安全策略限制为仅本人可读写。`anon public key` 可置于前端；请勿使用 `service_role` key。

1. 在 <https://supabase.com> 新建项目，区域选择较近的节点；
2. 在 **Project Settings → API** 复制 **Project URL** 与 **anon public key**；
3. 在 **SQL Editor** 中执行 [`supabase/schema.sql`](supabase/schema.sql) 的内容，结果应为 `Success. No rows returned`；
4. 打开应用的 **设置 → 云同步**，填写上述两项并保存，然后注册或登录账号；
5. 在其他设备重复第 4 步，登录同一账号，各点击一次「立即同步」。

**免注册（匿名）**：不填写邮箱与密码，点击「免注册使用（匿名）」即可同步。匿名账号与本浏览器绑定，清除站点数据后无法找回；跨设备共享请使用邮箱账号。自建项目需先在 **Authentication → Sign In / Providers** 中开启 `Anonymous sign-ins`。

| 按钮 | 行为 |
| --- | --- |
| 立即同步 | 拉取云端、与本机合并后上传；同一单词权重取较大值 |
| 从云端恢复 | 以云端数据覆盖本机 |
| 上传本机 | 以本机数据覆盖云端 |

常见错误：

- `Invalid login credentials`：多为尚未点击确认邮件中的链接，或密码错误；
- 「云端的 vn_state 数据表还没有创建」：第 3 步的 SQL 未执行成功；
- 同步报 401 或权限错误：确认已启用行级安全策略，且存在策略 `auth.uid() = user_id`。

## 数据与备份

数据保存在浏览器 `localStorage`（键名 `vn.state.v2`），可在 **设置 → 数据** 中导出或导入 JSON。AI Key 与 Supabase 配置同样只保存在本机。

清理浏览器数据或更换设备前，请先导出备份，或配置同步并执行一次「立即同步」。

## 常见问题

**点击喇叭无声音** — 发音使用浏览器语音合成或词典音频；iPad 需允许 Safari 播放声音，桌面端未安装英文语音包时回退至词典音频。

**手机无法打开电脑上的地址** — 确认两台设备连接同一 WiFi；Windows 防火墙首次询问时选择「允许访问」。

**添加到主屏幕后显示空白页** — 首次打开需完整加载一次（Service Worker 注册成功）。局域网 `http://` 地址在部分浏览器中不支持离线缓存，但可正常使用。

**更换设备后数据丢失** — 数据默认仅存于本机，请先配置同步并执行一次，或导出 JSON 后导入。

**清空数据** — **设置 → 数据 → 清空** 删除全部单词本；仅清空一个单词本时，右键该单词本选择「清空」。
