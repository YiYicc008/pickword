能否装成「独立窗口」取决于浏览器；快捷方式与书签在任何浏览器上都能用，但打开时需联网。

Windows（Edge / Chrome）

安装步骤

  1. 用 Edge 或 Chrome 打开 https://YiYicc008.github.io/pickword/index.html；
  2. 地址栏右侧会出现「安装 拾词」图标，点击它；也可以打开 ··· 菜单 → 应用 → 安装此站点为应用；
  3. 弹窗中可勾选「固定到任务栏」「创建桌面快捷方式」，然后点击 安装；
  4. 安装完成后，开始菜单与桌面出现「拾词」，双击即以独立窗口打开。

卸载：设置 → 应用 → 拾词 → 卸载；Chrome 也可在 chrome://apps 中右键卸载。

Android（Chrome / Edge / 华为浏览器 / 夸克）

安装步骤

  1. 浏览器打开同一网址；
  2. Chrome：右上 ⋮ → 安装应用（部分版本显示「添加到主屏幕」）；页面底部也可能直接出现「安装拾词」提示条；
  3. 确认后主屏幕出现图标，点击即独立窗口运行；
  4. 使用夸克、微信等内核较旧的浏览器时可能只有「添加到桌面」，那是快捷方式，打开后仍在浏览器中。

iPhone / iPad（Safari）

添加步骤

  1. 必须使用 Safari（微信内置浏览器、Chrome for iOS 均不支持安装）；
  2. 打开同一网址 → 点击底部（iPad 在顶部）的 分享 按钮；
  3. 在菜单中选择 添加到主屏幕 → 右上角 添加；
  4. 从主屏幕图标打开即为全屏、无地址栏。

删除图标即卸载，不会影响其他设备。

鸿蒙（HarmonyOS）

鸿蒙 4.x 及更早版本

系统兼容安卓应用，可用「华为浏览器」或 Chrome 打开网址，按上面的 Android 步骤安装或添加到桌面。

HarmonyOS NEXT

系统只接受 .hap 应用，网页没有系统级安装入口。可退而使用：

  • 浏览器菜单中的「添加到桌面」，生成打开网页的快捷方式；
  • 把网址加入浏览器书签，从书签进入。

不同版本、不同浏览器的入口名称可能不同，实际以系统显示为准。

没有安装入口时

手工创建快捷方式

  • Windows：桌面右键 → 新建 → 快捷方式 → 位置填 https://YiYicc008.github.io/pickword/index.html → 名称填「拾词」；
  • macOS：Safari 中把地址栏左侧的图标拖到桌面；
  • 手机：使用浏览器的「添加到主屏幕」，或把页面加入书签。

这种入口打开后仍带地址栏，且断网不可用，但不需要浏览器支持安装。

安装之后

  • 独立窗口运行，没有地址栏与标签页；
  • 首次打开需联网，之后由本地缓存提供，断网可用（字典查询、发音、AI 功能需要网络）；
  • 右键或长按图标，可使用快捷菜单：添加单词、新建单词本、词云视图、局域网直传（Chrome 桌面版与 Android 支持）；
  • 支持从其他应用分享文本到拾词（Android、Windows 的 Chrome）；
  • 双击 .json 备份文件时可用拾词打开并导入（Chrome 桌面版）。

常见问题

装好后打开是示例数据，或显示“雅思高频词”

说明安装的是带 ?demo 的地址。卸载后改为安装不带参数的地址：https://YiYicc008.github.io/pickword/index.html。

找不到「安装」按钮

iOS 使用「添加到主屏幕」；部分浏览器不支持安装，只能创建快捷方式；若已安装过，浏览器不会再显示安装入口。

已安装的图标打开仍是旧版本

关闭窗口再重新打开；仍不行时打开 检查页，点「清除缓存与 Service Worker」后重开。

卸载或清理浏览器数据会丢数据吗

会。数据保存在浏览器本地，卸载应用、清理站点数据都会清除。请在卸载或换设备前先用「导出备份」或配置同步。

两台设备装的是同一个应用吗

是同一份代码、同一个网址；但数据各自独立保存，需要共用请配置同步（见应用内「设置 → 云盘同步 / 云同步」）。

本页为静态说明，不依赖应用脚本，因此应用无法打开时也可访问。
